Où trouver les textes d'origine

  • Code du travail : le code sur Légifrance, la base ouverte de l'État (LEGI, DILA) d'où viennent les données, et la copie de cette base que nous avons utilisée (Hugging Face).
  • RGPD : le règlement (UE) 2016/679 sur EUR-Lex.
  • Les licences : Licence Ouverte 2.0 (Etalab) et Creative Commons BY 4.0.

Comment les textes sont préparés

Chaque article forme un passage, sauf s'il est très long : il est alors coupé en plusieurs. Chaque passage commence par une ligne de titre (le code, le numéro de l'article, les titres de la section). Le sens de chaque passage est ensuite enregistré, ce qui permet de chercher par le sens et non par les mots exacts.

Ce qui n'y est pas

  • La jurisprudence (les décisions de justice) et les conventions collectives.
  • Les modifications de la loi après le 13 juillet 2025 : un article modifié depuis apparaît dans son ancienne forme (un cas trouvé : L6123-5).
  • Les rectificatifs du RGPD publiés après le Journal officiel du 4 mai 2016 n'ont pas été vérifiés.

Seuls les textes officiels font foi. Mentions et licences complètes (GitHub)
